# Project page redirects

This site preserves browser links to the nanoGPT MacBook benchmark pages after
the project moved to [cenetex/nanogpt-macbook](https://github.com/cenetex/nanogpt-macbook).

`/nanogpt-macbook/` opens the new site. Browser links to deeper paths keep their
path, query, and section anchor. The redirect runs in the browser; API clients
should use the new address directly. Other paths retain the normal Pages response.

GitHub provides the separate HTTP redirect for the old repository and Git URLs.
The old repository name stays reserved for that redirect.
